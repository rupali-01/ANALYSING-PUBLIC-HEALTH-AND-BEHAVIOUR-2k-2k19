# ANALYSING-PUBLIC-HEALTH-AND-BEHAVIOUR-2k-2k19
This project aims to analyze and visualize health-related data,  focusing on mental health issues, suicide rates, and the prevalence of  various disorders in Kenya compared to global trends.  And an  Interactive Web  Application that makes the analysis accessible to a broader  audience, including researchers, policymakers, and the general  public.

🌍 Objective
Compare Kenyan mental health indicators with global trends

Identify patterns in mental illness prevalence, treatment coverage, and public health responses

Provide visual insights and descriptive statistics to support policy and awareness

🛠 Tech Stack
Language: R

Libraries: tidyverse, dplyr, ggplot2, readr, lubridate, scales

Tools: RStudio, RMarkdown

📊 Features
📥 WHO Data Import & Cleaning

🔍 Subsetting for Kenya and Global Data

📈 Trend Analysis (2000–2019)

📉 Visualization of Prevalence, Coverage & Outcomes

🧠 Focus on behavioral health indicators
